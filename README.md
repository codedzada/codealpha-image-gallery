# 📸 CodeAlpha - Modern Image Gallery

A responsive and interactive **Image Gallery** web application built as part of the CodeAlpha frontend internship task. It features category filtering, a smooth lightbox viewer with image navigation, and modern UI design using Tailwind CSS.

## 🔗 Live Demo
👉 https://codedzada.github.io/codealpha-image-gallery/

## 🚀 Features

* **Responsive Grid Layout:** Adapts seamlessly across mobile, tablet, and desktop screens.
* **Category Filtering:** Filter images instantly by categories (*All*, *Nature*, *Architecture*, *Technology*).
* **Lightbox Modal:** Click any image to view it in full screen with a blurred background overlay.
* **Next & Previous Navigation:** Easily browse through filtered images inside the lightbox.
* **Optimized Performance:** Fast loading times using Unsplash image parameters and lazy loading.

## 🛠️ Built With

* **HTML5**
* **Tailwind CSS** (via CDN)
* **JavaScript (ES6+)**
